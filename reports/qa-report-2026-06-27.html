3 visible elements have font-size < 12px at the 390px mobile viewport. All three Playwright browser projects reproduce the failure identically — this is a site-level CSS regression, not a test environment artifact.
Recommended fix for GraphLock dev team
Search responsive stylesheet for font-size values below 12px, including computed em/rem values that scale small at mobile. Check @media (max-width: 480px) blocks. Minimum readable size is 12px per WCAG 1.4.4.

@responsive · 3 failures
chromium-desktop mobile-chrome tablet
28–30 <img> elements in the app-screenshots/ gallery section are missing the alt attribute entirely. Note: alt="" is valid for decorative images — the violation here is a missing attribute, not an empty one. This fails WCAG 1.1.1 (Non-text Content).

Add descriptive alt text to each app screenshot (e.g. alt="GraphLock calculator — scientific mode"). For purely decorative images, use alt="" to tell screen readers to skip them. This is an accessibility bug; file with priority.
